# منصّة امتحانات اللغة العربية

- **الموقع للطلاب:** https://imissherhz-source.github.io/unit3-exam/
- **لوحة الأستاذ:** https://imissherhz-source.github.io/unit3-exam/admin.html

## الملفات
- `exams.json` — قائمة الامتحانات وترتيبها وإعدادات الصفحة الرئيسية (تُعدَّل من لوحة الأستاذ).
- `exams/<id>.json` — أسئلة كل امتحان وإجاباته المعتمدة.
- `index.html` — موقع الطلاب. `admin.html` — لوحة الأستاذ. `assets/style.css` — التصميم.

لوحة الأستاذ تحفظ مباشرة في هذا المستودع عبر GitHub باستخدام رمز دخول (Fine-grained token) بصلاحية Contents: Read and write على هذا المستودع فقط.
